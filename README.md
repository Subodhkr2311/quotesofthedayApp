# Quotes of the Day App

A simple and elegant Android application built with Java that displays daily quotes to inspire and motivate users. 

## 🚀 Features

Based on the repository's structure, this application includes the following core functionalities:

* **Daily Quotes Display:** View fresh, inspiring quotes directly on the main screen.
* **Interactive Dialogs:** Utilize a custom dialog box to interact with the app, likely for adding or managing quotes.
* **Modern UI Styling:** A clean and polished user interface featuring custom XML gradients.

## 🛠️ Tech Stack

* **Platform:** Android
* **Language:** Java (100%)
* **UI/Design:** XML (Custom layouts, dialogs, and gradients)
